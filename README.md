## Tentang

Fokus proyek saya saat ini adalah developer tools untuk API dan eksperimen smart contract di jaringan EVM.

## Proyek pilihan

- **[ScrapMe](https://github.com/yukensimi/ScrapMe)** — API workbench berbahasa Indonesia untuk menemukan spesifikasi OpenAPI/Swagger, menyusun request REST, membaca respons, dan mengekspor hasil. Dibangun dengan TypeScript, React, dan Express.
- **[FairDot](https://github.com/yukensimi/fairdot)** — protokol on-chain eksperimental yang merancang aturan exit lebih transparan melalui satu pool kanonis di Portaldot V3 EVM. Ditulis dalam Solidity.

## Teknologi yang sedang saya gunakan

`TypeScript` · `React` · `Node.js` · `Express` · `Solidity`
